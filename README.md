# 💻 Dnyaneshwar Zadokar — Portfolio Website

Welcome to my personal portfolio website built with **React.js**, **Framer Motion**, and **modern UI design** principles.
It showcases my work, projects, skills, and journey as a **Full Stack Developer** passionate about the **MERN Stack and AI integrations**.

## 🚀 Features

* 🎨 **Modern UI/UX** with a premium dark-mode aesthetic
* ⚡ Smooth **Framer Motion** animations (tilt, pulse, and scroll reveals)
* 💼 **Dedicated Sections**: Experience, Projects, Gallery, Certificates, and Resume
* 🧠 Tech-focused portfolio highlighting my AI, ML, and Full Stack work
* 📨 Functional contact form powered by **EmailJS**
* 🧩 Fully responsive design for all screen sizes

## ⚙️ Setup Instructions

To run this project locally on your machine:

```bash
# 1️⃣ Clone the repository
git clone https://github.com/dnyaneshwar-zadokar/Dnyaneshwar_Zadokar_Portfolio.git

# 2️⃣ Navigate to the project directory
cd Dnyaneshwar_Zadokar_Portfolio

# 3️⃣ Install dependencies
npm install

# 4️⃣ Run the development server
npm run dev
```

Now open [http://localhost:5173](http://localhost:5173) in your browser 🚀
